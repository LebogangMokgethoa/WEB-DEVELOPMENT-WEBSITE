## Project Overview
Paws Animal Shelter is a fictional community-based non-profit organisation created for this module, dedicated to rescuing, rehabilitating, and rehoming stray, abandoned, and surrendered animals. The organisation currently has no website and relies solely on a single social media page, which limits discoverability and offers no structured way for visitors to enquire about adoption, volunteering, or donating.

This repository contains the front-end build of a five-page website for Paws Animal Shelter, developed in three stages across the WEDE5020 Portfolio of Evidence (POE): static HTML structure (Part 1), CSS styling and responsive design (Part 2), and JavaScript functionality (Part 3).

**Brand identity:**
- **Slogan:** Rescue. Love. Rehome.
- **Tagline:** Every Paw Deserves a Warm Home
- **Colour palette:** Navy, blue, and cream

## Website Goals and Objectives
- Increase the number of adoption enquiries generated through the website.
- Grow the shelter's donor and volunteer base.
- Raise awareness of the shelter's work and available animals.

**KPIs:** adoption enquiry form submissions, volunteer/sponsor sign-ups, and website traffic to the adoptable pets page, tracked monthly.

## Key Features and Functionality
| Page | File | Purpose |
|---|---|---|
| Home | `index.html` | Hero section, brand introduction, calls to action |
| About Us | `about.html` | Shelter history, mission, vision, and team |
| Adoptable Pets | `services.html` | Profiles of six adoptable animals with care needs |
